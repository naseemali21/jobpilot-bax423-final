# **JobPilot: Smart Job Matcher & Resume Builder**

## **Overview**

JobPilot is a multi-stage recommendation system that matches job seekers to relevant job descriptions using semantic retrieval, profile-aware filtering, multi-factor ranking, adaptive feedback, and AI-powered resume tailoring.

The system was developed as a final project for BAX 423 and demonstrates modern recommendation-system techniques including embeddings, FAISS retrieval, re-ranking, explainability, feedback learning, and generative AI.  
---

## **Features**

### **Job Recommendations**

* Upload a resume PDF  
* Extracts skills automatically  
* Generates a structured candidate profile  
* Retrieves semantically similar jobs using FAISS  
* Applies profile-aware filtering  
* Ranks jobs using multiple signals  
* Explains why jobs were recommended

### **Resume Generation**

* Select a recommended job  
* Generates a tailored resume draft using Gemini 2.5 Flash  
* Preserves factual resume content  
* Improves ATS keyword alignment  
* Downloads generated resume

### **Batch Analytics**

* Top skills  
* Top hiring locations  
* Top employers  
* Common job titles  
* Salary coverage analysis

### **Feedback Learning**

* Accept / Reject / Skip recommendations  
* Updates ranking weights based on user feedback  
* Re-ranks recommendations during the session  
* Demonstrated improvement through simulated interaction rounds

## **Installation**

\*\*Recommended Evaluation Order\*\*

1\. Run the Streamlit application (app.py) to interact with the completed recommendation system.

2\. Review BAX423\_Final.ipynb to examine the data-ingestion pipeline, embedding generation, FAISS index construction, ranking evaluation, and adaptive learning experiments used to build the application artifacts.

The application does not require the notebook to be executed first because all required artifacts are included in the submission.

**Steps:**

Download and extract the submitted project ZIP file. Keep the folder structure unchanged.

\*The project relies on relative file paths (for example, data/... and artifacts/...), so all files and folders must remain in their original locations.

The original TechMap JSON file was approximately 50 GB and is not included in the submission. To make the notebook reproducible, a smaller raw JSONL sample is used at data/techmap\_jobs\_sample\_30000.jsonl. The notebook streams this sample line-by-line, deduplicates records, and creates the processed job snapshot used downstream.

**From a terminal, navigate into the extracted project directory before launching the application:**

cd Ali\_Naseem\_BAX423\_Final

**Install dependencies:**

pip install \-r requirements.txt

**Run application:**

streamlit run [app.py](http://app.py)

**\*Since some systems don’t have pip or streamlit in PATH, you can do the following instead:** 

**Install dependencies:**

python3 \-m pip install \-r requirements.txt

**Run application:**

python3 \-m streamlit run app.py

**If running on macOS and Streamlit crashes due to file watcher issues:**

python3 \-m streamlit run app.py \--server.fileWatcherType none

The core recommendation engine functions without the API key.

## **Troubleshooting**

If installation fails due to torch or sentence-transformers, create a Python 3.10 virtual environment:

python3.10 \-m venv venv

source venv/bin/activate

pip install \-r requirements.txt

streamlit run [app.py](http://app.py)

## **Dataset**

Source:  
TechMap International Job Postings Dataset

Original Size:  
50.39 GB JSON

File Size used:  
381.9 MB

Processed Snapshot:  
25,000 postings

The ingestion pipeline incrementally processes large JSON job records, performs deduplication, and creates a 25,000-job snapshot used by the deployed application.

An Adzuna API ingestion module is included in BAX423\_Final.ipynb to demonstrate retrieval, standardization, and deduplication of live job postings. The deployed Streamlit application currently uses the preprocessed 25,000-job snapshot for reproducible recommendations.  
---

## **Limitations**

* Salary data was largely unavailable in the source dataset.  
* Resume generation quality depends on Gemini output quality.  
* Job postings originate from 2021 and may not reflect current openings.
